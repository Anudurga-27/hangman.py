                                        **Hangman Game in Python**
Project Description

This is a simple **Hangman Game** developed using Python. The game randomly selects a word from a predefined list, and the player has to guess the word by entering one letter at a time.

The player is given a maximum of **6 wrong guesses**. The game ends when the player successfully guesses the complete word or uses all the available chances.

🎯 Aim

To develop a simple and interactive Hangman game using Python programming concepts such as loops, conditions, lists, user input, and the random module.

✨ Features

- 🎲 Randomly selects a word
- 🔤 Allows the player to guess letters
- ✅ Displays correct guesses
- ❌ Counts wrong guesses
- 🔄 Prevents repeated letter guesses
- 🏆 Displays a winning message
- 💀 Displays Game Over when all chances are used

🛠️ Technologies Used

- **Python**
- **Random Module**

🧠 Concepts Used

- Variables
- Lists
- `if-else` statements
- `for` loop
- `while` loop
- Functions from the `random` module
- User input
- String operations
